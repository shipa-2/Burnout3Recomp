A very WIP PC port of Burnout 3 based on the Xbox version. 

Based on the static recompilation method used by [Unleashed Recompiled](https://github.com/hedge-dev/UnleashedRecomp).

I've provided a very lazy proof of concept demo in [Releases](https://github.com/mxmstr/Burnout3-recomp/releases).
It simply patches the original XBE into the final recompiled EXE.

My recompiler is here: https://github.com/mxmstr/XenonRecomp

Developed with the assistance of Claude.
